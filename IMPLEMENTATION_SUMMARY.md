## 💡 Customization Guide

### Change Colors

Edit primary colors in Tailwind classes:

```tsx
// Change from teal-600 to any Tailwind color
className="bg-teal-600"  → className="bg-blue-600"
```

### Update Content

Find and replace text in sections:

```tsx
"Voicing the Right to Learn" → Your headline
"contact@sejbd.org" → Your email
```

### Add Images

Replace emoji icons with images:

```tsx
<div className="text-6xl">📚</div>
// Replace with: <Image src="..." alt="..." />
```

### Add Forms

Replace buttons with actual form components:

```tsx
<button onClick={handleSubmit}>Subscribe</button>
// Replace with: <form onSubmit={handleSubmit}>
```
