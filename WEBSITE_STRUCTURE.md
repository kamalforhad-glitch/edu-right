## Design Elements

### **Color Scheme**

- **Primary**: Blue (#1e40af) & Teal (#0d9488)
- **Secondary**: White (#ffffff), Gray (#111827)
- **Accents**: Purple, Green, Orange (for thematic areas)
- **Background**: Light gradients (blue-50, teal-50)

### **Typography**

- **Headlines**: Bold, 2xl-6xl sizes
- **Body**: Regular gray-700 for readability
- **Emphasis**: Bold for key points

### **Components**

- Card-based layouts
- Gradient backgrounds
- Icons and emojis for visual interest
- Hover effects on buttons and links
- Responsive grid system (1 col mobile, 2-3+ cols desktop)
